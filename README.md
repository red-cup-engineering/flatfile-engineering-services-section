# Data Services Section

This section groups Red Cup Engineering capability cells that operate on
data itself — normalizing, structuring, or conforming content — as distinct
from the transport, chain, and platform sections that move or settle it.
Each data domain gets its own `<domain>-services-section` child under
`services/`.

## What's here

- `services/` — one `<domain>-services-section` child per seated data
  domain.

The first domain seated here is
[`text-services-section`](services/text-services-section/), for
capability cells that operate on text and Markdown prose.
