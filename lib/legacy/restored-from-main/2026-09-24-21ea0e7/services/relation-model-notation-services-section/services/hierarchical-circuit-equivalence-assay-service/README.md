# Hierarchical Circuit Equivalence Assay Service

This service independently checks bounded FOUR behavior and sovereign assembly
equivalence for hierarchical RMN circuits. It emits assay evidence; it does not
authorize a circuit, apply effects, or replace the circuit owner.

Version `1.0.9` was recovered from Git commit `e03fb87c721` because the current
recursive infomaterial fabrication service contracts that exact version while
the internal registry stopped at `1.0.8`. The executable source is seated with
RMN engineering rather than restored to the deleted science-tree runtime shell.

Provider records may be redirected with
`HIERARCHICAL_CIRCUIT_EQUIVALENCE_STATE_ROOT`; an operator must keep mutable
state outside an immutable installed release.
