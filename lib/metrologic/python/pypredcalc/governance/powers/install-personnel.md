# Install personnel into an office

The steward may install a candidate (human personnel or LLM-backed agent) as the incumbent
of an office. Installation settles both required predicates of `office-as-double-settlement`
on the candidate: **recognition** (`recognized-as-incumbent-of`) and **induction**
(`inducted-into`), reaching the *dignitas* state — full incumbency.

Until installation by the steward, an agent acting in an office's role does so informally:
the substrate has no incumbency cells settled. The agent may exercise the office's powers
as a practical matter, but the normative layer does not formally attribute those exercises
to the office.

## Recognition + induction

- **Recognition**: backward-sensitive. Witnesses of prior performance accumulate; the
  community knows the candidate as legitimately holding the office.
- **Induction**: forward-obligating. The candidate has accepted the office's duties.

Installation by the steward asserts both cells in a single substrate increment.

## Current state

All pypredcalc offices are currently held informally — no incumbency cells have been
settled. Formal installation is deferred to a future task (likely the substrate-driven
`pyfars run pypredcalc/` work) when incumbency-as-substrate-data becomes operationally
load-bearing.
