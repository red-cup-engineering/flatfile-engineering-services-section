# Immunity from non-captain C amendment

The steward bears immunity from any office below the captain attempting to amend the
charter's hard-core C. The correlate disability prevents non-captain offices from changing
the steward's hard-core obligations.

## What this protects

Hard-core C is amendable only via [`amend-hard-core`](amend-hard-core.md), which requires
captain ratification. An office below the captain — including the steward's peers (XO,
corpus-tracker), the functional offices (developer, records-officer), or the substrate
itself acting via automated dispatch — cannot:

- Modify a charter commitment (C1–C4).
- Add or remove a charter commitment.
- Change the substrate-binding semantics of a charter commitment.

## What this does not protect

- The captain may amend C; the steward proposes (`amend-hard-core`) and the captain ratifies.
- Guidelines tier and below (G1–G5, preferences, instructions) are amendable via
  [`ratify-governance-rule`](ratify-governance-rule.md), which the steward holds without
  needing captain ratification.
