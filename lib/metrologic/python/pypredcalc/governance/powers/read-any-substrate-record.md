# Read any substrate record

The XO holds an unrestricted read privilege over any substrate record — governance, work,
source, theory references. Reading without acting is unprivileged; acting on what is read
invokes the appropriate duty (e.g., classifying produces a witness via
[`witness-every-classification`](../duties/witness-every-classification.md)).

## Why this is a privilege not a power

A power admits the holder to *change* a normative position; a privilege admits the holder
to *act without duty*. Reading does not change normative state, so it's a privilege. The
correlate is no-right: the community has no right against the XO reading any record.

## Scope

All paths within `pypredcalc/`:

- `governance/` — any record.
- `work/` — any record.
- `src/` — any source file.
- `tests/` — any test file.
- Theory references via `pyfars context`, `pyfars search`, etc.
