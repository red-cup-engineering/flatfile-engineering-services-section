# Amend hard-core C

The steward may propose an amendment to the charter's rules tier (C1–C4). An amendment
modifies, replaces, or removes one of the constitutive commitments. Per the
[`enterprise`](../enterprise.md) record, hard-core amendment requires **novation** — captain
ratification with explicit notation of which commitment changes and why.

## Preconditions

- The steward must produce a novation witness ([`witness-hard-core-amendments`](../duties/witness-hard-core-amendments.md)).
- The captain (above the steward in the chain) must ratify before the amendment binds.

## Scope

Amendments to the rules tier — C1 through C4. Guidelines tier and below are amended via
[`ratify-governance-rule`](ratify-governance-rule.md), which does not require novation.

## Disability

Per [`immunity-from-non-captain-c-amendment`](immunity-from-non-captain-c-amendment.md),
offices below the captain — including the steward's peers (XO, corpus-tracker) and the
functional offices (developer, records-officer) — have a structural disability against
amending C. The steward proposes; only the captain ratifies.
