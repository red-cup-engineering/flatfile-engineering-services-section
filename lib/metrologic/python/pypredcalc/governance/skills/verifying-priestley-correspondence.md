# Verifying Priestley correspondence

## Requirements

- Topology-specialist office.
- A finite bounded distributive lattice `D`.

## Steps

1. Build the **prime-filter space** `X(D)`: filters of `D` that are prime (closed under
   `∧`; if `a ∨ b ∈ F`, then `a ∈ F` or `b ∈ F`).
2. Topologize `X(D)`: the topology is generated by clopen up-sets `U_a = {F : a ∈ F}`
   for `a ∈ D`.
3. The opposite direction: from a Priestley space `(X, ≤, τ)`, build the lattice of
   clopen up-sets.
4. Verify the round-trip: starting from `D`, build `X(D)`, build the clopen up-set
   lattice of `X(D)`, get back `D` up to isomorphism.
5. For finite `D` (the case pypredcalc handles), enumerate explicitly.

## Outcomes

A witness confirming the bijection on the chosen `D`. Each round-trip cell pair is
checked; failures localize to where the bijection breaks.
