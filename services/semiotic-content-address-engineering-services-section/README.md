# Semiotic content address engineering services section

Computer Data's holding for the semiotic content address: canonical NFC/CBOR carrier commitments, raw-byte RFC 6920 NI addresses, and the source-domain audit that diagnoses competing content identities.

## Apps

- `apps/semiotic-content-address-engine` is the engine, package `@red-cup-engineering/semiotic-content-address`. Its own README states source custody, upstream owners (URI Services for NI grammar, CBOR Services for deterministic CBOR, Cryptographic Data for hashing) and downstream consumers (SignCell and the Sign family).
  Its repository slug `semiotic-content-address-system` is historical; the checkout is the repository's unchanged history.
