# Text Services Section

This section groups Red Cup Engineering capability cells that operate on
text and Markdown prose.

## What's here

- `services/` — one capability cell (or further section) per seated text
  operation.

The first cell seated here is
[`semantic-linefeed-normalization-service`](services/semantic-linefeed-normalization-service/),
which normalizes Markdown prose to semantic linefeeds (one sentence per
line) without changing Markdown structure.
