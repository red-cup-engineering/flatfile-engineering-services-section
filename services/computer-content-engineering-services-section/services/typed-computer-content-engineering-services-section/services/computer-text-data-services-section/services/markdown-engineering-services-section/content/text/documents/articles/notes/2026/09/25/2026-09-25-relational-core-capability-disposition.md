The retired Python `relationing` package presented Structure, Language, Geometry, and Physics as four layers. Only three independent computational effects were present: finite powerset-frame operations, bounded closure and fixed-point operations, and typed lambda-term normalization. Its `Flow`, `Nucleus`, `Discipline`, profile, and `RelationalPhysicalSystem` classes add no further carrier or transformation: the advertised physics operation is an injected `flow(state)` endomap. The package has no live modern consumer.

The effects now have direct, upstream homes.

| Effect | Modern carrier | Modern realization |
| --- | --- | --- |
| Finite powerset, order, joins, finite suprema, d-frame receipts | Code | `computer-code-engineering-services-section/closure/finite-frame` over caller-supplied names and readings. |
| FOUR-reading d-frame vocabulary | Code, SignChain binding | `computer-code-engineering-services-section/signchain/d-frame`; the finite-frame kernel remains independent of SignCell. |
| Bounded settlement, closure ordinals, formal contexts and concepts | Code | `computer-code-engineering-services-section/closure/*`. |
| Typed lambda reduction, products, lists, finite sums, and empty elimination | Code | `computer-code-engineering-services-section/semiotic-expression-notation`, with capture-safe de Bruijn substitution, evaluation, typing, JSON schema, and named-surface codec. |

No networking or system package is created. The old reference package had no peer, persisted relational data, protocol, or stateful service. A generic endomap is already a function supplied by its caller; wrapping it as a `Flow` or calling repeated invocation "physics" creates maintenance machinery without a new observable effect.

The legacy named-variable substitution was not capture-safe. Its genuine reduction cases are retained through the modern de Bruijn notation, including sum injection and scoped case elimination. Its `reflex` wrapper does not create a separate reduction or value; an identity lambda already expresses that same effect. The legacy proof-search and finite semantic wrappers had no consumer or stable relation carrier, so they are not promoted into a new language, theory service, or system.

The abstract mathematics remains science, not an engineering claim. Finite Heyting frames, closure operators, and fixed points may be used where a concrete carrier and its invariants are supplied. This retired package's finite examples do not establish a general relational geometry or physics. Engineering retains only the executable transformations above; any future scientific claim needs its own definitions, evidence, and stated scope.
