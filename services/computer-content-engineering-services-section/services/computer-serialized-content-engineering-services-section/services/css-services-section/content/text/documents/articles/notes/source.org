* Introduction
*/Bellybrush Theme/* is a CSS theme for styling /Teraum/ reference
books and other materials.
* Bellybrush Theme
** Design Philosophy
The /Bellybrush Theme/ theme is based on my own *Oats*, which is based
on another of my themes, *Brutstrap* which claims to style content as
it's constructed.

However, /Brutstrap/ is catered toward a rather stark aesthetic, to make
it more readily match the [[https://brutalist-web.design][brutalism]] advocated by [[https://naildrivin5.com/][David Bryant
Copeland]].

Bellybrush is more light-hearted. It's designed to be used for a set
of reference books I'm written for a funny fantasy setting, and so
hopefully reflects that.
