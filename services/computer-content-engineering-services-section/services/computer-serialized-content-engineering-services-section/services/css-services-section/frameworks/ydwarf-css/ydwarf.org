* Design Philosophy
The /YDwarf/ theme is based on a client's request for a website which
would have a landing page containing a sales-letter, a second
sales-letter, and finally a link to a form page.
* CSS Rules
All of /YDwarf/'s CSS lives in a single style-sheet, ~ydwarf.css~.
** Base Rules
The theme's */base rules/* are those that go with HTML tags directly.
*** HTML Tag Rules
Document-wide settings, including those relevant to font-styling, are
declared in the ~html~ rule.
