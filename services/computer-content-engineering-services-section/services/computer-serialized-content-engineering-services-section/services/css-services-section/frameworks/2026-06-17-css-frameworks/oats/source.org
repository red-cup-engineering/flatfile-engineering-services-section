* Design Philosophy
The /Oats/ theme is based on my own [[https://emsenn.net/projects/brutstrap/][/Brutstrap/]], which claims to style
content as it's constructed.

However, /Brutstrap/ is catered toward a rather stark aesthetic, to
make it more readily match the [[https://brutalist-web.design][brutalism]] advocated by [[https://naildrivin5.com/][David Bryant
Copeland]].

/Oats/ tries to be a little softer and more friendly. While
nothing about the stylesheet contradicts the brutalist priciples
Copeland provides, it does a little more styling than is strictly necessary.

All of /Oats/ CSS lives in a single style-sheet, ~oats.css~.
** Base Rules
The theme's */base rules/* are those that go with HTML tags directly.
*** HTML Tag Rules
Document-wide settings, including those relevant to font-styling, are
declared in the ~html~ rule.
#+BEGIN_SRC css
  html {
    color: #444;
    background-color: #eee;
#+END_SRC
These colors are the lowest-contrast, three-digit hex codes that still
pass [[https://www.w3.org/TR/WCAG20/][WCAG2 AAA]].
#+BEGIN_SRC css
    hyphens: auto;
    font-family: sans-serif;
    letter-spacing: .03em;
    word-spacing: .05em;
    line-height: 1.4;
    font-size: 1.3rem;
  }
#+END_SRC
Adding some spacing between letters and words helps make the document
feel a little more "friendly," and makes it a little safer to use more
distinctive fonts in your body text.
